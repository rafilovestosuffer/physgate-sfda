\section{What a source-free bearing-diagnosis result should carry}
\label{sec:recommendations}
The measurements motivate the following reporting requirements.
\begin{enumerate}
\item \textbf{Bearing-disjoint targets for unseen-bearing claims.} Keep physical specimens out of the source, including healthy specimens. If a dataset cannot support this, state which deployment scenario its evaluation estimates.
\item \textbf{A distribution over source splits.} Report paired effects and conditional intervals over pre-specified draws, plus per-bearing outcomes where specimens rotate between seen and unseen roles. Distinguish partition variability from uncertainty for new bearings.
\item \textbf{A source-only comparison.} Report the gap before adaptation beside the adapted one, and the adaptation effect on each target arm. Non-significance alone does not establish no effect.
\item \textbf{Paired module comparisons.} Use the same source checkpoint and job for ungated, gated and oracle arms; retain checkpoint hashes where possible. Report the distribution of differences, not only separate averages.
\item \textbf{A precisely defined oracle reference.} Our oracle withholds incorrect existing pseudo-labels and retains correct ones; it does not replace predictions with true labels. Report which intervention is used and avoid treating a non-convex oracle run as a proven upper bound.
\item \textbf{A non-adaptive baseline and comparable metrics.} Use identical splits, report class weighting and evaluation units, and include balanced accuracy when class proportions differ.
\item \textbf{False acceptance, fault-family precision and coverage.} Report healthy counts by bearing and distinguish silence from a healthy verdict. Give downstream gains on certified and silent records separately, and compare the module inside adaptation with direct use of its verdicts on the records it certifies. Any calibration or validation with verified healthy target-rig recordings is target-rig supervision and must be declared.
\item \textbf{Model-selection and implementation checks.} State whether source or target labels select checkpoints, document hyperparameters and validate sample-index alignment in pseudo-label pipelines. The released target-label selection rule added 0.6 points on leaky and 1.0 on clean targets on average here.
\end{enumerate}
For practice, the central implication is to validate the intended unseen-bearing use case explicitly. More source specimens together with more training data improved the forest in this study; whether diversity alone supplies that benefit is unresolved. A kinematic gate with low observed false acceptance may improve the measured transductive result, but limited coverage and off-rig false alarms preclude a general safety claim.
